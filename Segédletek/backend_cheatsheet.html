JOIN lekérdezések

INNER JOIN — csak egyező sorok

SELECT r.rendeles_id, u.nev, t.nev AS termek
FROM rendelesek r
INNER JOIN ugyfelek u
  ON r.ugyfek_id = u.id
INNER JOIN termekek t
  ON r.termek_id = t.id;

-- Csak azok jelennek meg ahol MINDKÉT
-- oldalon van egyező sor.

LEFT JOIN — bal tábla összes sora

SELECT u.nev, r.rendeles_id
FROM ugyfelek u
LEFT JOIN rendelesek r
  ON u.id = r.ugyfek_id;

-- Ha az ügyfélnek nincs rendelése,
-- r.rendeles_id = NULL lesz.
-- Bal tábla (ugyfelek) MINDIG megjelenik.

Aggregáció + GROUP BY

SELECT u.nev,
       COUNT(r.id) AS rendeles_db,
       SUM(r.osszeg) AS total
FROM ugyfelek u
LEFT JOIN rendelesek r ON u.id = r.ugyfek_id
GROUP BY u.id, u.nev
HAVING COUNT(r.id) > 2
ORDER BY total DESC;
HAVING = GROUP BY utáni szűrés (mint WHERE, de aggregált értékre)

Subquery (allekérdezés)

WHERE-ben

-- Átlag feletti fizetésű alkalmazottak:
SELECT nev, fizetes
FROM alkalmazottak
WHERE fizetes > (
  SELECT AVG(fizetes)
  FROM alkalmazottak
);

-- IN-nel:
SELECT nev FROM ugyfelek
WHERE id IN (
  SELECT ugyfek_id FROM rendelesek
  WHERE osszeg > 10000
);

FROM-ban (derived table)

-- Átlagot előbb kiszámol, aztán szűr:
SELECT nev, avg_fizetes
FROM (
  SELECT osztaly, AVG(fizetes) AS avg_fizetes
  FROM alkalmazottak
  GROUP BY osztaly
) AS osztaly_atlag
WHERE avg_fizetes > 500000;
A FROM-ban lévő subquerynek alias kell (AS osztaly_atlag)

Algoritmus fogalma
Az algoritmus egy feladat megoldásának lépéseinek végesen sok, egyértelmű, elvégezhető, determinisztikus utasítás sorozata. Bemeneti adatokból kimeneti adatokat állít elő.

Jó algoritmus jellemzői

  • Végesség – véges lépésben leáll
  • Meghatározottság – minden lépés egyértelmű
  • Hatékonyság – kevés erőforrással
  • Általánosság – hasonló feladatokra is

Komplexitás jelölés

JelölésNevePélda
O(1)KonstansTömb elem olvasás
O(log n)LogaritmikusBináris keresés
O(n)LineárisLineáris keresés
O(n²)NégyzetesBuborékrendezés

Algoritmus típusok

  • Keresés – elem megtalálása
  • Rendezés – sorrend kialakítása
  • Összesítés – összeg, átlag, max/min
  • Rekurzió – önmaga hívja magát
  • Szűrés – feltételnek megfelelők
Keresési algoritmusok

Lineáris keresés – O(n)

Sorban végigmegyünk minden elemen. Rendezetlen tömbben is működik.

function linearisKeres(tomb, cel) {
  for (let i = 0; i < tomb.length; i++) {
    if (tomb[i] === cel) return i; // index
  }
  return -1; // nem találta
}

Bináris keresés – O(log n)

Csak rendezett tömbön! Felezi a keresési tartományt minden lépésben.

function binarisKeres(tomb, cel) {
  let bal = 0, jobb = tomb.length - 1;
  while (bal <= jobb) {
    let kozep = Math.floor((bal+jobb)/2);
    if (tomb[kozep] === cel)  return kozep;
    if (tomb[kozep] < cel)   bal = kozep + 1;
    else                        jobb = kozep - 1;
  }
  return -1;
}
Rendezési algoritmusok

Buborék rendezés – O(n²)

Szomszédos elemeket hasonlít és cserél. Lassú, de egyszerű.

function buborekRendezes(tomb) {
  let n = tomb.length;
  for (let i = 0; i < n-1; i++) {
    for (let j = 0; j < n-i-1; j++) {
      if (tomb[j] > tomb[j+1]) {
        [tomb[j], tomb[j+1]] = [tomb[j+1], tomb[j]];
      }
    }
  }
  return tomb;
}

Min/Max keresés – O(n)

function minimumKeres(tomb) {
  let min = tomb[0];
  for (let i = 1; i < tomb.length; i++) {
    if (tomb[i] < min) min = tomb[i];
  }
  return min;
}

// JS beépített:
Math.min(...tomb);
Math.max(...tomb);

Összesítés (összeg, átlag)

function atlag(tomb) {
  const osszeg = tomb.reduce((a, b) => a + b, 0);
  return osszeg / tomb.length;
}

// Kötelező mező:
if (empty(trim($_POST['nev']))) {
  $hibak[] = "A név kötelező!";
}

// Hossz ellenőrzés:
if (strlen($nev) < 2 || strlen($nev) > 50) {
  $hibak[] = "Név 2-50 karakter!";
}

// Szám ellenőrzés:
if (!is_numeric($kor) || $kor < 0) {
  $hibak[] = "Hibás kor!";
}

// Hibák kiírása:
if (!empty($hibak)) {
  foreach ($hibak as $hiba) {
    echo "<p class='error'>$hiba</p>";
  }
}

filter_var() – beépített szűrők

// Email validálás:
filter_var($email, FILTER_VALIDATE_EMAIL);

// URL validálás:
filter_var($url, FILTER_VALIDATE_URL);

// Szám validálás:
filter_var($szam, FILTER_VALIDATE_INT);
filter_var($szam, FILTER_VALIDATE_FLOAT);

// Szanitálás (tisztítás):
filter_var($str, FILTER_SANITIZE_STRING);
filter_var($int, FILTER_SANITIZE_NUMBER_INT);

// Regex validálás:
if (!preg_match('/^[a-zA-Z\s]{2,50}$/', $nev)) {
  $hibak[] = "Hibás névalak!";
}
JavaScript Kliens oldali validálás

Form validálás eseménnyel

document.getElementById('form')
  .addEventListener('submit', function(e) {

  const nev   = document.getElementById('nev').value.trim();
  const email = document.getElementById('email').value.trim();
  let hibak = [];

  if (nev.length < 2) {
    hibak.push("Kötelező a név!");
  }

  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(email)) {
    hibak.push("Hibás email!");
  }

  if (hibak.length > 0) {
    e.preventDefault();
    document.getElementById('hibak').innerHTML
      = hibak.map(h => `<p>${h}</p>`).join('');
  }
});

MintaMire illeszkedik
